## Server (`src/server/auth/dataset-ctx.ts`)
```ts
export interface DatasetDenied { denied: Module; verb: 'view' }
export function isDenied(v: unknown): v is DatasetDenied;
export async function datasetCtx(locals: App.Locals, module: Module): Promise<CoreCtx | DatasetDenied>;
export async function readDataset<T>(locals: App.Locals, module: Module, fn: (ctx: CoreCtx) => Promise<T>): Promise<T | DatasetDenied>;
```
- `datasetCtx`: `const ctx = await getCoreCtx(locals); if (!ctx) throw error(401, 'Authentication required');` (same as `requireCoreCtx`); `if (locals.user?.role === 'admin') return ctx;` `if (!locals.user?.supabaseId) return { denied: module, verb: 'view' };` `const caps = await resolveCapabilities(ctx.tenantId, locals.user.supabaseId); return caps.can(module, 'view') ? ctx : { denied: module, verb: 'view' };`
- `readDataset`: `const c = await datasetCtx(locals, module); return isDenied(c) ? c : fn(c);`
- Serialisation: the marker is plain JSON; SvelteKit ships it in `__data.json` like any value.

## Client (`src/lib/components/ui/DataSource.svelte`)
```ts
interface Props<T> { value: T | DatasetDenied; module?: Module; compact?: boolean; children: Snippet<[T]> }
```
Renders `children(value)` when `!isDenied(value)`, else `AsyncBoundary` `{ kind: 'forbidden', title: m.data_denied_title({ dataset: moduleLabel(value.denied) }), description: m.data_denied_hint() }` (compact: one-line variant). `isDenied` for the client lives in `src/lib/permissions.ts` (same shape check; no server import).

## Fetch helper mapping (K3)
In the hub's shared JSON fetch helper (locate with `git grep -n "async function fetchJson\|export async function apiFetch" -- src/lib`; if none is shared, add `src/lib/api/fetch-json.ts` and use it only where this spec's slices touch): a GET that returns 403 with body `{ message | error }` matching `/^([a-z]+): view required$/` resolves to `{ denied: <match>, verb: 'view' }` instead of throwing.

## Module attribution for the ratchet
`moduleForLoadPath(file)`: strip `src/routes/(app)` and route groups, take the canonical path prefix, longest match against `MODULE_MANIFEST[*].appPrefixes` (`src/lib/modules/availability.ts`) plus the static map `{ '/finances': 'finance', '/socials': 'ads', '/work': 'projects', '/workforce': 'projects', '/sales': 'sales', '/support': 'support', '/memberships': 'memberships', '/brains': 'brains', '/agents': 'agents', '/channels': 'channels' }`; anything else → `overview`.

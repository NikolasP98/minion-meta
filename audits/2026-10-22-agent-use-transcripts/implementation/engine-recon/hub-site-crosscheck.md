The pending UUID is the chat idempotency/run identity; it is not that RPC frame ID or a server authority grant. A returned Promise means send attempted, not server acceptance or completed work.

## Confirmed Site/gateway source incompatibility

Follow-up read against exact Gateway candidate `7fac6744ea9f15fb64b0423bd4f3c39592b3e6a7`: `src/gateway/protocol/schema/frames.ts:41` permits a non-empty role string structurally, but `src/gateway/server/ws-connection/message-handler.ts:378–386` semantically accepts only `operator` or `node`. No member-to-operator translation occurs before this guard. `src/gateway/server-core/server-methods.ts:230–231` would also reject non-operator regular methods, but the earlier handshake guard is the first mismatch for the inspected Site client. This confirms incompatible source contracts between these exact checkouts; no claim is made that this Site/Gateway combination is deployed or that the rejection was reproduced against a live service.

## Interpretation and limits

The prior product expectation of the same personal agent, current RBAC and backend capabilities across private transports is consistent with reusing the gateway engine; it does not mean every frontend/transport already has equivalent lifecycle, browser tooling, auth admission or receipt coverage. This report refreshed those distinctions from source. Any wider parity statement needs the gateway transport/admission/agent/model report, installed artifacts and separately authorized runtime evidence. No fixes are proposed as shipped here and no additional model/network calls were made.

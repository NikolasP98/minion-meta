## Three-table native store

Use application identity MSR1/0x4D535231 and user_version 1, distinct from bridge MSJ1. Use parameterized statements, STRICT tables, foreign keys and exact schema/object/constraint/index identity. Freeze complete SQL definitions before native qualification.

| Table | Immutable fields and constraints |
| --- | --- |
| metadata | Singleton id=1; canonical persisted schema/profile/count policy. |
| runs | Organization, shell, run, session, invocation, optional scoped caller key, input digest, input-policy version, startedAt, canonical complete admission metadata and reserved_bytes=81920. Unique internal run identity; unique invocation identity; partial unique (org_id,shell_id,invocation_key) WHERE invocation_key IS NOT NULL; composite unique (org_id,shell_id,run_id) for terminal ownership. |
| terminals | One row per run; owning organization/shell/run composite foreign key; canonical outcome and stable canonical receipt; event identity and digest; unique (org_id,shell_id,event_id). No terminal replacement or receipt rewrite. |

There is no global or per-shell one-open-run index. Distinct organizations/shells may hold unresolved admissions concurrently. Per-shell execution scheduling remains a separate sender/admission policy; heartbeat activeRunIds does not establish SQL ownership or capacity.

Do not persist prompts, multimodal parts, raw errors, credentials or opaque usage. Canonical errorMessage remains bounded sender-supplied public-safe text; byte/digest validation does not prove arbitrary accepted text is redacted. Preserve validated text exactly. Use complete serialized admission metadata for the 16 KiB check, including organization, optional key, canonical admission and input-policy version. SQL text/character length cannot replace UTF-8 byte accounting, especially for NUL-containing identifiers. Physical scalar/index duplication is outside the logical reservation claim.

Require an absolute canonical path under a trusted private owned parent, with no linked ancestors/main/sidecars, regular owned single-link 0600 main/sidecars and no orphan WAL/SHM. Preflight existing nonempty stores read-only before mutation. Refuse foreign, corrupt, unexpected-schema, bridge-journal or altered-policy files without relabeling them. Revalidate schema/policy within operations. Preserve the 11-07 same-UID/trusted-parent limitation: preflight cannot prevent hostile pathname/inode replacement between native opens. No hostile-filesystem guarantee is claimed.

Use WAL, synchronous=FULL, foreign_keys=ON and trusted_schema=OFF; inspect effective settings. BEGIN IMMEDIATE serializes writes across handles and organizations. Expose the minimal synchronous store operations below. Exact TypeScript names may follow existing local conventions, but ownership and return semantics are fixed:

- assertReady(): synchronously verify open state and compatible persisted schema/policy in a bounded native read; it grants no tenant authority and does not deny a full store that must still accept replay/terminal commits. Manager negotiation uses this check through the same stopping/local-operation gate.
- lookupInvocation({orgId,shellId,invocationKey,sessionId,inputDigest}): return the original admission for an exact key; absent returns no record; changed session/digest conflicts. It checks no current registry/bridge and never forwards.
- admit(serverOwnedMetadata): repeat the scoped-key lookup inside the write transaction BEFORE count checks. Return {created:false,admission} on exact replay. Otherwise enforce both retained counts and metadata reservation, insert immutable server-issued identity, COMMIT, then return {created:true,admission}. A no-key request is distinct. Internal identity collision must refuse rather than replace another row.
- commitOutcome(orgId,unknownOutcome): canonicalize, recompute fixed SHA-256, require exact admitted shell/run/session/invocation/input tuple, and compare any existing canonical terminal. Exact replay returns its original receipt without new identity/time. Otherwise generate a stable native receipt identity/time, enforce nested/aggregate reservation, insert the terminal and receipt in one transaction and return only after COMMIT. Event/identity/content conflicts roll back; an oversized terminal leaves the original obligation intact.
- getOutcome(orgId,shellId,runId): return the canonical not_found/unresolved/committed query shape from immutable admitted ownership. Missing and wrong-org lookups share not_found. Registry deletion and bridge presence do not alter history. Validate decoded rows and canonical byte bounds; do not trust malformed persisted JSON.
- close(): idempotent; subsequent operations refuse with a bounded closed/unavailable surface. Opening/closing responsibility remains with the injected store owner.

No public update/delete/forward-retry API is added. Only the committed created:true result grants a process-local initial-forward permission. Admission surviving a commit-to-send gap remains unresolved; lookup/reopen does not recreate permission.
